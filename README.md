# 💩 Симулятор жидкого стула

Интерактивная браузерная симуляция вязкой коричневой жидкости на HTML5 Canvas.
Частицы взаимодействуют по упрощённой модели «притяжение + отталкивание»,
подчиняются гравитации и собираются в лужу на дне экрана.

Проект представляет собой **один HTML-файл** — никаких зависимостей, сборщиков
и установки. Просто откройте его в браузере.

---

## 📸 Что внутри

- **Физика частиц**: гравитация, вязкость, отталкивание, трение о дно.
- **Пространственная сетка** для быстрого поиска соседей (1000+ частиц при 60 FPS).
- **Непрерывная подача** при зажатой мыши — «струя» следует за курсором.
- **Поддержка тач-устройств** (мобильные браузеры).
- **HUD** со счётчиком активных частиц.

---
